# Titanic-EDA-Analysis
Exploratory Data Analysis on the Titanic dataset using Python (Pandas, Seaborn, Matplotlib). Includes visual insights, statistical summaries, and a structured PDF report.

# Titanic EDA Project

This repository contains an Exploratory Data Analysis (EDA) of the Titanic dataset using Python. The project includes data cleaning, visualization, and analysis of key features to understand passenger demographics and survival patterns.

## Files Included

- `Titanic_EDA.ipynb` – Jupyter Notebook with complete EDA and visualizations  
- `Titanic.csv` – Dataset used for analysis  
- `Titanic_EDA_Report.pdf` – PDF summary report of findings

## Tools Used

- Python  
- Pandas  
- Matplotlib  
- Seaborn

## Key Insights

- Class, gender, and age had a significant impact on survival.  
- Female passengers had a much higher survival rate than males.  
- Passengers in 1st class were more likely to survive compared to those in lower classes.
